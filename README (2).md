# بيان — موقع مكتب الشيخ عقيل بن محمد زيد المقطري

## خطوات التشغيل

### ١. إنشاء مشروع Supabase
1. أنشئ مشروعًا جديدًا في [supabase.com](https://supabase.com) باسم `bayan-office`
2. من **SQL Editor** نفّذ ملف `supabase-schema.sql` كاملاً (ينشئ الجداول ويهيئ الصلاحيات)
3. من **Project Settings > API** انسخ:
   - `Project URL`
   - `anon public key`
4. افتح `index.html` وابحث عن هذين السطرين في أعلى `<script>` الأخير، واستبدل القيم:
   ```js
   const SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
   const SUPABASE_ANON_KEY = 'YOUR-ANON-KEY';
   ```

### ٢. إنشاء حساب دخول لفريق بيان (لوحة التحكم)
من **Authentication > Users** في Supabase، أضف مستخدمًا (بريد إلكتروني + كلمة مرور) لكل فرد من فريق الشيخ سيدير المحتوى. هذا الحساب هو ما سيُستخدم لتسجيل الدخول من زر "لوحة التحكم" في الموقع.

### ٣. النشر (بنفس أسلوب تراث وكيان)
- ارفع الملفات (`index.html`, `manifest.json`, `sw.js`) إلى مستودع GitHub جديد (اقترحنا `Bayan_Office`)
- فعّل GitHub Pages من إعدادات المستودع
- **مهم بخصوص اليمن**: بما أن GitHub لا يعمل داخل اليمن، يجب إعداد Cloudflare Worker كوسيط أمام GitHub Pages (بنفس الطريقة المستخدمة مع تراث لتجاوز الحجب الجغرافي)

### ٤. أيقونات التطبيق (PWA)
أضف صورتين للشعار الذي سيصممه Maged داخل مجلد `icons/`:
- `icon-192.png` (192×192 بكسل)
- `icon-512.png` (512×512 بكسل)

## هيكل الملفات
```
Bayan_Office/
├── index.html          # الموقع كاملاً (عام + لوحة تحكم) — ملف واحد
├── supabase-schema.sql # مخطط قاعدة البيانات (نفّذه مرة واحدة فقط)
├── manifest.json        # إعدادات PWA
├── sw.js                # Service Worker للعمل دون اتصال
└── icons/                # أيقونات التطبيق (تُضاف لاحقًا)
```

## الجداول في قاعدة البيانات
- `lessons` — الدروس والمحاضرات
- `fatwas` — الفتاوى
- `programs` — البرامج الدعوية
- `team_members` — أعضاء الفريق (جاهز للاستخدام المستقبلي، لم يُربط بالواجهة بعد)
- `site_settings` — نبذة الشيخ، الآية المعروضة، روابط التواصل

## ملاحظات
- لوحة التحكم حاليًا تدير: الدروس، الفتاوى، البرامج، وإعدادات النبذة/التواصل
- قسم "الفريق" (team_members) جاهز في قاعدة البيانات لكن يحتاج ربطًا بالواجهة في مرحلة قادمة
- التصميم البصري نفسه الذي تمت الموافقة عليه (هوية المخطوطات: حبر داكن + أحمر التصحيح + برونزي)
